# Cohort-calibrated prototypes for few-shot open-set recognition

[![DOI 10.5281/zenodo.23695548](https://zenodo.org/badge/DOI/10.5281/zenodo.23695548.svg)](https://doi.org/10.5281/zenodo.23695548)

Code, fixed episode manifests and recorded results of I. Adjei-Mensah and A. A. Baffour, *Cohort-calibrated prototypes for few-shot
open-set recognition*, Neurocomputing (submitted, 2026).

In eight registered single-pass test rounds, CCP-A raises the AUROC of every ResNet-12 host on mini-ImageNet by 0.58-4.44 points, by
1.84-5.50 points under transfer to CUB, and by 0.86-8.03 points in all eight CLIP configurations. It lowers AUROC in 16 of 24 DINOv2
configurations, and validation SCG has a Spearman rank correlation of 0.78 with the foundation-model test gains.

## Install and reproduce

```bash
git clone https://github.com/adu-baffour/cohort-calibrated-prototypes && cd cohort-calibrated-prototypes
python -m venv .venv && source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt && pip install -e . --no-deps
```

1. **From the recorded results** (CPU, about 2 minutes): `python scripts/reproduce.py all --tier 1` regenerates and checks Tables 1-8,
   Figures 2-4 and the detailed results, and ends with "tier 1: all OK".
2. **From the released checkpoints** (GPU): `python scripts/reproduce.py val-equivalence --tier 2` re-evaluates every host on validation.
3. **From scratch** (GPU-days): `python scripts/reproduce.py training --tier 3` prints the training commands.

[REPRODUCE.md](REPRODUCE.md) has every step, a quickstart and the repository map.

## Data and checkpoints

The FRN and DNPG checkpoints and the recorded per-episode metrics and score caches are in release v2.0.0
(https://github.com/adu-baffour/cohort-calibrated-prototypes/releases/tag/v2.0.0) and on Zenodo
([10.5281/zenodo.23695548](https://doi.org/10.5281/zenodo.23695548)); unpack them into one folder and set `CCP_ASSETS` to it. The datasets
are public benchmarks prepared by `scripts/prepare_data/` (docs/data.md); third-party weights are listed in docs/checkpoints.md. The RFS
CIFAR-FS checkpoint is not redistributed because the RFS code has no license; it is available from the authors on request. Figures 1 and 4
show mini-ImageNet images and are not redistributed.

We build on the code and released models of FEAT, SnaTCHer, FRN, TANE, DNPG, RFS, CLIP, and DINOv2, and on the tieredImageNet copy distributed by learn2learn.
