# Names: paper and registration

Generated by `python scripts/make_results_docs.py` from `ccp/naming.py`; do not edit by hand.

The paper's names are used everywhere in this repository except inside the verbatim recorded files and registration documents (results/, bundles/, manifests/, docs/preregistration/, docs/prereg_variants.md), which are never edited and keep the names under which the experiments were registered and run. `ccp.recorded.load` translates recorded keys to the paper's names on reading (`paper_names=False` returns them unchanged); `ccp.naming.recorded_key` maps back.

## Two names that mean different things

- **H2 and H3.** The paper's H2 (validation SCG predicts the test gain) is the registration's **H2b**, and the paper's H3 (test SCG, descriptive) is the registration's **H2**. The registration's own **H3** is a third, exploratory analysis: whether, within DINOv2 ViT-S, ViT-B and ViT-L, the gain falls as COSF AUROC rises. It is reported in Section 5.5.3 of the paper, not as a hypothesis. A reader who looks up H3 in docs/preregistration/foundation_round.md therefore finds the model-size analysis.
- **D1 and SCG.** The stratified cohort gap (SCG, Eq. 8) was called **D1** in the registration documents and recorded files (keys `d1`, `d1_valA`, `d1_test`; files `d1_val.json`, `d1_test.png`). D1 is not related to the score D of a trained host.

## Hypotheses (foundation-model round)

| Registration | Paper | What is tested |
|---|---|---|
| `H1` | H1 | CCP-A improves AUROC over COSF (one-sided Wilcoxon per configuration, Holm over the 32 configurations) |
| `H2b` | H2 | validation (valA) SCG is positively rank-correlated with the test AUROC gain (one-sided permutation Spearman) |
| `H2` | H3 | test SCG is positively rank-correlated with the test AUROC gain (descriptive: same episodes) |
| `H2b-s` | H2 within-group | H2 within the 8 dataset x shot groups (mean within-group Spearman, permutation within groups) |
| `H2-s` | H3 within-group | H3 within the 8 dataset x shot groups |
| `H3` | model-size trend (exploratory) | within DINOv2 S -> B -> L, does the gain fall as COSF AUROC rises (description only; Section 5.5.3) |
